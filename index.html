Questions Fréquentes - GPS Mali

Oui, le GPS SinoTrack fonctionne dans tout le Mali. Il utilise le réseau 4G/LTE disponible dans les villes principales et passe automatiquement en 3G/2G dans les zones rurales. Une carte SIM locale (Orange Mali, Malitel, etc.) avec forfait data est requise.

Le ST-901L possède un relais permettant de couper le moteur à distance via l'application (idéal pour véhicules professionnels ou à risque). Le ST-901 standard offre toutes les fonctions de suivi mais sans contrôle moteur, à un prix plus abordable.

À Bamako: Oui, installation professionnelle incluse dans certains packs.
En région: Nous fournissons un guide d'installation détaillé avec photos et vidéos, ainsi qu'un support téléphonique pour vous aider.

Non, pas de frais mensuels de notre part. Les seuls frais récurrents sont ceux de votre forfait data (environ 1.500-3.000 FCFA/mois selon l'opérateur). L'application SinoTrack est totalement gratuite.

Bamako: Livraison à domicile ou point de retrait sous 24h.
Régions: Expédition via transporteurs (SOTREMA, etc.) sous 2-5 jours ouvrables.
Frais: Variable selon la destination (2.000-5.000 FCFA).
